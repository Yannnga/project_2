# Exoplanet Explorer
Project video link: https://youtu.be/Bs_a-yx1cgY

## Project Description
Solar System Explorer" is a Python program developed using Pygame that allows users to explore the solar system. Users can view the Sun and the eight planets, observe the planets as they orbit the Sun, and click on various celestial bodies to learn basic information about them.

## Features
1.Displays the Sun and the eight planets.

2.Simulates the orbits of planets around the sun.

3.Click on a celestial body to display its related information.

4.Display the name, radius, and orbital period of celestial bodies.

5.Load planetary information from a JSON file.

## Files

`celestial_body.py`- Defines celestial bodies and their movement.

`settings.py`- Stores program settings.

`solar_system_explorer.py`- Main program and user interaction.

`solar_system.py`- Creates and manages the Solar System.

`test_planet_function.py`- Tests planetary data using unittest.

`data/planets.json` - Planetary information.

`requirements.txt` - Required Python packages.

## Data Source

Planetary data is based on approximate astronomical values.
